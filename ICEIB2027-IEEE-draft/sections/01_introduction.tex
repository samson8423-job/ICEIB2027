\section{Introduction}\label{sec:intro}
% G--L: context, challenge, literature, judgment, contributions, organization.
Physical inactivity motivates tools that help people get started with exercise \cite{who_pa}. A runner with only half an hour may still need to look up the weather, find a route, and decide how to record the session. We want to make these steps available through a single request.

Activity logging, voice assistants, pose analysis, and language-model coaching each address part of this problem. Our question is whether one agent can use weather and routes to propose a run and stay within a daily token budget. Speech and a digital human are planned for feedback. Their effect on response time and cost needs to be measured.

The proposed contributions are a conversational path from planning to logging, a shared tool interface for running and nutrition, and a scope and quota check before model use. Section~\ref{sec:related} outlines related work. Sections~\ref{sec:method} and~\ref{sec:experiments} describe the design and evaluation plan. Section~\ref{sec:conclusion} outlines the next steps.
