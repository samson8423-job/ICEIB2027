\begin{abstract}
Planning a run often involves checking the weather, choosing a route, and deciding how long to run. Recording the activity may require additional manual steps. We propose AI Fitness Coach, a browser-based coach that accepts text and voice. One agent would access weather, route, activity, and nutrition tools after a scope and quota check. The interface would present results as text, cards, and speech with a digital human. We plan to test the main user flows through human ratings and automated latency and usage measurements. The first goal is to demonstrate the planning and logging flows within free-tier quotas.
\end{abstract}
