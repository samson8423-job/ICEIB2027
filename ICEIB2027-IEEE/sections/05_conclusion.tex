\section{Conclusion}\label{sec:conclusion}
This paper presented AI Fitness Coach, a conversation-first domain AI agent for personalized running guidance. A single FitnessCoachAgent, governed by a non-LLM ScopeGuard and a per-day token budget, integrates weather, routes, activity logging, food-image estimation, and MCP-based nutrition suggestions, and delivers its output as text, cards, speech, and a lip-synced digital human. The design targets a publicly accessible deployment on free-tier infrastructure.

The contribution at this stage is the system design and a concrete evaluation protocol. Measured performance, baseline comparisons, and ablation results are not yet available, and the latency values in this paper are targets. Limitations include reliance on free-tier API quotas, the use of manually verified routes, and the absence of continuous GPS or sensor data.

Future work includes continuous mobile GPS tracking, step counting and posture sensing, lower-cost digital-human generation, long-term user memory, and larger user studies. Completing the planned evaluation is the immediate next step.
